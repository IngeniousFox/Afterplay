Data backups

Your library, sessions and stats live in one small database file. Afterplay keeps a rotating local copy automatically; Back up now saves an extra one wherever you want. Game save files are separate: see Saves.

Restore the backup from Nov 20, 03:00?

Afterplay will save a safety copy of today's library, replace the database with this one and restart.

  • Changes since then are not in it: 2 sessions and 1 note.
  • The safety copy stays in the backups folder until you delete it.
  • Other PCs keep their data. The next sync reconciles them.
